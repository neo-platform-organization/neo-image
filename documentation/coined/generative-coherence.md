# Generative coherence

Proposed during the neo design discussion in November 2026.

A few consistent organizing ideas enable many useful capabilities. The
architecture lets those capabilities reinforce one another rather than
requiring a disconnected mechanism for every feature.

Examples motivating the term include Lisp's symbolic program structures,
Smalltalk's message-based object world and Haskell's pure function composition
and types. Their capabilities still require implementation work; coherence does
not make features free or prove performance, security or correctness.

This names a quality to assess, not a certification that neo has achieved it.
[Interpretive neutrality](interpretive-neutrality.md) names one specific
principle proposed for neo, rather than the general quality of the design.
