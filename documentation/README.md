# neo language and image

- [Coined terms](coined/README.md): interpretive neutrality and generative coherence.

- [Language v1 contract](language-v1.md): implemented semantics, current limits,
  and unfinished requirements, with independent acceptance evidence.

Warp is the canonical serialized object graph. Weft is an object-oriented
source view; Knight expresses pure calculations inside that graph. Their
implemented subsets are described in [runtime format](runtime-format.md).

The sole canonical image is [image.neo](../neo-os/image.neo). It contains
foundation examples, a framebuffer exercise, and the lifecycle exercise.
